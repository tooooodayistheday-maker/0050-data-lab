# 0050 Dara Lab

0050 Data Lab 是一個以元大台灣50 ETF (0050) 為主題的資料工程與資料分析學習專案。

## Current Features
- 商品價格換算成約等於多少股 0050

## Learninng Goals

- Python
- Git & Github
- Data Analysis
- Data Engineering
- SQL
- API
- Web Scraping
- Data Visualization
- Vue
- Chrome Extension
